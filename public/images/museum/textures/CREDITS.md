# Museum PBR texture credits

All texture sets in this directory are from [ambientCG](https://ambientcg.com),
released under **CC0 1.0 Universal** (public domain — no attribution required,
credited here anyway). Downloaded as 1K JPG sets and recompressed.

| Prefix       | ambientCG asset | Used for                         |
|--------------|-----------------|----------------------------------|
| `woodfloor_` | WoodFloor051    | Gallery floors                   |
| `plaster_`   | Plaster001      | Gallery walls / ceilings         |
| `marble_`    | Marble012       | Rotunda floor, plinths           |
| `concrete_`  | Concrete034     | Solitary-cell room               |
| `metal_`     | Metal032        | Cell door, fixtures              |
| `fabric_`    | Fabric020       | Theater benches                  |
| `wood_`      | Wood067         | Picture frames, benches, vitrine |

Map suffixes: `_col` albedo, `_nrm` OpenGL normal, `_rgh` roughness,
`_ao` ambient occlusion, `_met` metalness.

Three.js (r160, MIT) is vendored at `public/js/three/`.
